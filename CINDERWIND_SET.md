# Cinderwind — Finalized Kit

## Passive — Phoenix's Wrath
Whenever Burn is successfully inflicted on an enemy by a character, Cinderwind immediately uses Skill 1, Phoenix Strike, against that enemy as an Extra Action. The trigger is application-only; Burn damage does not trigger it. Phoenix Strike cannot recursively trigger Phoenix's Wrath.

Base limit: 2 Extra Actions per Cinderwind turn. Flamebound stacks increase the limit by +1 each.

## Skill 1 — Phoenix Strike
Deals 80% ATK Blaze damage to one enemy. No additional effects. It is Cinderwind's Basic Attack and Extra Action attack.

## Skill 2 — Flamebound
Gain 1 Flamebound stack for 2 turns. Maximum 3 stacks. Each stack increases the Extra Action limit by 1. Reapplying Flamebound refreshes its 2-turn duration.

Cinderwind also gains 1 Flamebound stack (same 2-turn refresh, same 3-stack cap) whenever an enemy is defeated, no matter what defeated it: her own attacks, her allies, or Burn/Soul Burn damage. Soul Burn applications trigger Phoenix's Wrath exactly like Burn.

## Skill 3 — Vermilion Rebirth
Deals 160% ATK Blaze damage to all enemies and applies 1 Burn stack to each surviving enemy for 2 turns. Each successful Burn application triggers Phoenix's Wrath normally and is subject to the current Extra Action limit.

## Core loop
Build Flamebound → increase Extra Action limit → team applies Burn → Cinderwind fires Phoenix Strike automatically.
